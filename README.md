## DÉLIE Frontend

Клиентска част (публичен сайт) за парфюмния магазин DÉLIE – каталог, категории, количка, акаунт и SEO. Изграден с Next.js (pages router), MongoDB/Mongoose и styled-components.

### Стартиране (development)

```bash
npm install
npm run dev
```

По подразбиране фронтендът работи на `http://localhost:3001`.

Необходими са коректни променливи в `.env` (MongoDB, S3 и др.), вкл. `MONGODB_URI` към същата база, която използва админ панелът.

### Как се показват парфюмите

- Продуктите се съхраняват в колекцията `products` (модел `Product`).
- Списъците се визуализират в:
  - `pages/perfumes.js` – каталог с филтър и търсене
  - `pages/perfume/[slug].js` – детайлна страница за парфюм
  - `pages/categories.js` и `pages/category/[slug].js` – страници по категории
- Данните идват от същата база, която се използва от админ панела.

### Процес от админ панела до сайта

1. Създай категории в админ панела.
2. Добави парфюми (име, марка, обем, цена, наличност, снимки).
3. Парфюмите се показват на началната страница, в `/perfumes` и в съответните категории.
